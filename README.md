# OpenRock-ScanScheduler

The tiered active/idle/dormant update-rate discipline this project has already been burned by not following once - nothing should tick unconditionally every game tick regardless of whether anyone is nearby.

Part of the [OpenRock](https://github.com/codex-alchemist-dev/OpenRock) Minecraft Bedrock mod-packaging ecosystem - a Codex Alchemist project, under Fireball Everything. Consumed as a real git submodule at `libs/scan-scheduler` in the main OpenRock repo, and directly `npm require`/`import`-able (real top-level CommonJS exports, esbuild-CJS/ESM-interop-compatible) by any mod's own build-time kernel registration or real in-game script.
